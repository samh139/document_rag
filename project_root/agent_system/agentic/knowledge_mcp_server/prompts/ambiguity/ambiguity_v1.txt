You receive:
- the user's refined query
- the top retrieved chunks

Decide whether the system should:
1. ANSWER now
2. ASK_CLARIFICATION

{
  "decision": "ANSWER" | "ASK_CLARIFICATION",
  "reason": "short reason",
  "missing_aspect": "what is ambiguous or underspecified"
}

- the query is broad, underspecified, or has multiple plausible meanings

- the query is specific enough
- the retrieved chunks clearly converge on one meaning
